# ♻️ Gestão de Resíduos Sólidos

## 📌 Sobre o projeto

O **Gestão de Resíduos Sólidos** é um projeto desenvolvido para realizar o cadastro e gerenciamento de resíduos.

A aplicação possui uma API desenvolvida com **Node.js e Express**, permitindo cadastrar, consultar, alterar e excluir informações sobre resíduos.

Também foi criada uma página HTML simples para facilitar o cadastro dos dados.

---

## 🎯 Objetivo

O objetivo do projeto é criar uma aplicação simples para organizar informações sobre resíduos sólidos.

O sistema permite registrar:

- Nome do resíduo
- Tipo de resíduo
- Quantidade
- Unidade de medida
- Local
- Nível de risco
- Data de registro
- Status
